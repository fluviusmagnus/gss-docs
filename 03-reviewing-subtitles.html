审校字幕 ​

结合表格、视频和时间轴，逐条核对并修改字幕。

你可以在本页完成什么 ​

  • 选择和编辑字幕单元格。
  • 让表格焦点、视频位置和时间轴保持同步。
  • 调整字幕开始和结束时间。
  • 在同集或跨集字幕之间导航。
  • 撤销、重做或检查当前修改。

浏览和选择字幕 ​

点击表格单元格会聚焦对应字幕行。左侧行标记可建立明确的行选择；拖动单元格可建立矩形范围；按住 Ctrl（macOS：Command） 可以追加范围，按住 Shift 可以扩展当前选择。

表格左上角的选择框用于选择或取消选择所有当前可见行。筛选开启时，隐藏行不会被行操作选中。

进入多选状态时，视频会暂停，避免播放跟踪改变正在批量处理的目标。重新单击普通单元格会回到单一焦点行。

编辑原文与译文 ​

双击可编辑单元格，或直接键入内容开始编辑。按 Enter 提交后焦点保持在对应行，便于继续使用键盘导航。

常见字段：

字段用途
episode字幕所属集数
start / end毫秒形式的权威时间
text原文字幕
translation译文字幕，主要审校字段
start_h / end_h人类可读时间
duration_h、chars、cps自动计算的时长、字符数和阅读速度

自动计算字段是只读的；编辑译文或时间后会重新计算。隐藏的元数据列可在 设置 → 显示隐藏列 中显示，但修改前应确认自己理解其用途。

复制、粘贴和填充内容 ​

选中单元格后可使用 Ctrl+C（macOS：Command+C）、Ctrl+X（macOS：Command+X）、Ctrl+V（macOS：Command+V） 或右键菜单。应用支持：

  • 包含多行文本的单元格。
  • 从电子表格复制的 HTML 表格。
  • 将矩形数据粘贴到当前可见行。
  • 使用选区右下角的填充柄向下复制可编辑内容。

明确的行选择不允许直接剪切或清空，防止未复制的整行内容被删除。派生字段也不能清空或粘贴覆盖。

播放和切换视频 ​

视频区域提供：

  • 上一个、播放/暂停、下一个。
  • 当前视频选择器。
  • 播放时间和进度。
  • 播放速度。
  • 时间轴缩放。

点击视频画面或按 Space 可切换播放状态。使用上下方向键跳转字幕不会擅自改变当前播放/暂停状态。

当焦点移动到另一集字幕时，应用会切换到匹配视频；视频加载完成后再恢复目标行和播放位置。没有匹配视频时会显示“视频缺失”，字幕仍可继续编辑。

使用时间轴定位字幕 ​

  • 点击时间轴空白处：移动播放头，并聚焦该时间点的字幕；间隙中会选择之前最近的一条。
  • 点击字幕块：跳转到对应字幕并让表格重新获得键盘焦点。
  • 鼠标滚轮：调整时间轴缩放。
  • 手动横向滚动或拖动：暂时保留当前视野，避免播放头立即把时间轴拉回。

播放时，当前字幕、表格焦点、行高亮和活动字幕块会同步。搜索或筛选正在使用时，播放跟踪不会抢回当前编辑焦点。

调整字幕开始和结束时间 ​

  1. 先聚焦一行字幕。
  2. 点击视频工具区的 调整时间。
  3. 输入开始和结束时间，或点击 使用播放头。
  4. 检查当前播放头和警告。
  5. 点击 应用时间。

时间格式使用 HH:MM:SS.mmm，也接受逗号毫秒分隔。结束时间必须晚于开始时间。

如果新时间与其他字幕重叠，或会改变该行在当前集的时间顺序，应用会先显示警告。确认无误后可以选择 仍然应用。

拖动时间轴字幕块只更新编辑器草稿，点击应用前不会直接写入工作区。

在字幕和集数之间导航 ​

  • Arrow Up / Arrow Down：上一条或下一条字幕。
  • 视频区 上一个 / 下一个：在边界处切换到相邻集，并聚焦第一条或最后一条字幕。
  • 顶部集数选择器：直接切换目标集。
  • 质量摘要、拼写检查和查找结果也可以跳转到目标行。

重叠时间范围内，手动聚焦的字幕在自身时间范围中保持优先；普通连续播放则优先显示开始更晚的字幕。

撤销和重做修改 ​

点击顶部 撤销、重做，或使用快捷键。单元格编辑、替换、行操作和机器翻译应用通常会进入历史记录。

以下操作有特殊边界：

  • 字幕重新导入会形成新的工作区历史边界。
  • 使用字幕 整体替换 重建匹配分集会清空之前的撤销/重做记录，但未匹配分集仍会保留。
  • 导出不会改变工作区或历史记录。
  • 保存后仍可撤销保存前的编辑；是否已保存与能否撤销是两件事。

重置工作区视图 ​

重置视图用于清除筛选和临时视图状态，并恢复有效焦点；顶部 重置布局用于恢复列宽。它们不会删除字幕内容。

遇到问题 ​

  • 点击字幕后表格跳动：确认是否正在播放或切换视频；暂停时点击已可见行通常不会主动滚动。
  • 上下键没有切换字幕：先关闭正在编辑的输入框或对话框，让焦点回到表格/视频区域。
  • 时间无法应用：检查格式和结束时间；有警告时先审查重叠或排序变化。
  • 视频缺失：字幕仍可编辑；到 项目设置 修复视频映射。
