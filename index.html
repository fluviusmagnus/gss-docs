GridSubStudio 用户手册 ​

GridSubStudio 是面向字幕翻译、审校和交付的桌面编辑器。本手册按实际工作任务组织，帮助你从导入素材开始，完成字幕编辑、质量检查、机器翻译和最终导出。

本手册覆盖 Windows x64 和 macOS Apple Silicon。Mac 测试版要求 macOS 27.0+；安装及 Gatekeeper 放行步骤见开始使用。

下载 GridSubStudio联系与支持

第一次使用 ​

建议依次阅读以下页面：

  1. 开始使用：新建或打开项目，认识主工作区。
  2. 导入素材：导入字幕和视频，确认文件所属集数。
  3. 审校字幕：使用表格、视频和时间轴完成日常审校。

按任务查找 ​

  • 效率工具：查找、筛选、批量编辑和处理字幕行。
  • 质量检查：定位阅读速度、行长、时间和拼写问题。
  • 机器翻译：配置翻译服务，运行任务并审查结果。
  • 保存与导出：保存工作并导出 CSV、XLSX、SRT 或 ASS。
  • 设置与帮助：调整界面、检查更新和排查常见问题。
  • 授权管理：获取、安装、更新或移除离线授权，并处理导出受限问题。
