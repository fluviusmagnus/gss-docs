Install ​

The Windows package is an .msi; run it and start GridSubStudio from the Start menu or desktop shortcut. The macOS package is a .dmg; open it, drag GridSubStudio.app into Applications, eject the disk image, then launch the app. Full steps are in Getting Started.

The Mac test build is not signed or notarized by Apple, so the first launch may be blocked by Gatekeeper. After confirming the package came from a trusted source, allow this app individually with the Gatekeeper steps in Getting Started.

Downloads and licensing ​

Downloads are free. Without a license you can still create and open projects, import material, edit and save, run quality checks, and use machine translation; only exporting subtitles requires a valid license. See License Management to request and install one.

Updates ​

Installed users should use Check for updates inside the app first; it only receives packages for the current platform and architecture, and a Mac update never installs a Windows package. If automatic updates fail, download the current package from this page and install it again; project.json and workspace.csv in the project folder are not affected. See Settings and Help for troubleshooting.
