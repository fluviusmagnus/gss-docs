下载 GridSubStudio ​

Windows 与 macOS 分开发布，版本号可能不同。按当前系统选择安装包即可，两个平台使用相同的项目和字幕审校流程。

Windows x64

Windows 10 / 11，64 位

版本 0.10.16 · 发布于 2026-09-16

下载 MSI

GridSubStudio_0.10.16_x64_en-US.msi

macOS Apple Silicon 未公证测试版

macOS 27.0 或更高版本

版本 0.10.17 · 发布于 2026-10-02

下载 DMG

GridSubStudio_0.10.17_aarch64.dmg

下载不收费；导出字幕需要有效授权。 查看授权管理。 已安装的用户优先使用应用内的检查更新。 更新与故障处理。

安装 ​

Windows 安装包是 .msi，按提示完成安装后从开始菜单或桌面快捷方式启动。macOS 安装包是 .dmg，打开后把 GridSubStudio.app 拖进「应用程序」，推出磁盘映像再启动。完整步骤见开始使用。

Mac 测试版未经 Apple 签名和公证，首次打开可能被 Gatekeeper 拦截。确认安装包来自可信渠道后，按开始使用中的放行步骤为该应用单独添加例外。

下载与授权 ​

下载不收费。没有授权也可以新建和打开项目、导入素材、编辑与保存、运行质量检查和机器翻译；只有最终导出字幕需要有效授权。申请和使用授权见授权管理。

更新 ​

已安装的用户优先使用应用内的检查更新，它只会收到当前平台和架构的包，Mac 更新不会安装 Windows 包。自动更新失败时，可以从本页下载当前版本重新安装；项目文件夹里的 project.json 和 workspace.csv 不受影响。排查方法见设置与帮助。
