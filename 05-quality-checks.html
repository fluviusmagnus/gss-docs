质量检查 ​

集中发现并处理阅读速度、行长、时间和拼写问题。

你可以在本页完成什么 ​

  • 使用项目阈值定位长译文和高 CPS 字幕。
  • 跳转到缺少集数、缺少译文、无效时间或时间重叠的行。
  • 使用本地词典检查译文拼写。
  • 管理忽略词和用户词典。

设置质量检查标准 ​

在 项目设置 → 其他参数 中设置：

  • 最大 CPS：每秒允许的最大译文字符数。
  • 行长：单行译文的建议最大字符数，也用于断行工具。
  • 拼写检查语言：当前项目使用的已安装词典。

这些阈值用于提示和筛选，不会自动修改字幕。

查找过长字幕 ​

表格工具栏显示 长行：数量。点击它可以只显示超出行长阈值的字幕，再次关闭筛选可回到完整工作区。

字符数保留空格，但不计算真实换行或字幕换行符。可根据语义选择缩短译文、使用 断行，或使用 拆分 生成多条字幕。

查找阅读速度过高的字幕 ​

点击 高 CPS：数量 筛选问题行。CPS 根据译文字符数和字幕持续时间计算。

常见处理方式：

  • 精简译文。
  • 在不影响画面和语义的前提下延长时间。
  • 拆分信息过多的字幕。

修改译文或时间后，字符数和 CPS 会自动更新。

检查字幕时间和完整性 ​

表格底部/侧边摘要会显示校验状态。可能的项目包括：

  • 无效时间范围：时间缺失、格式不可用或结束不晚于开始。
  • 缺少分集：字幕行没有有效集数。
  • 缺少译文：译文字段为空。
  • 时间重叠：同一集相邻字幕范围发生重叠。

点击对应摘要会跳到下一个问题行，而不是把其他字幕隐藏。反复点击可循环检查同类问题。

时间编辑器会在应用重叠或顺序变化前再次提醒。校验提示不是自动修复；应结合视频确认正确时间。

启用拼写检查 ​

  1. 打开 设置。
  2. 启用 检查译文拼写。
  3. 点击 词典，选择一个已安装词典。
  4. 等待后台检查完成。

拼写检查只扫描 translation 字段。大型工作区会分批处理，检查过程中仍可编辑。没有安装词典时，拼写检查器按钮不可用。

查看和应用拼写建议 ​

按 F7 或点击 拼写检查 打开检查器。

  1. 使用 上一个、下一个 在错误间导航。
  2. 在建议列表中选择替换词。
  3. 点击 应用 修改当前单元格。

跳转时表格会跟随目标行。直接在表格中修正拼写也会更新检查结果，并尽量保持当前编辑焦点。

忽略拼写提示 ​

  • 忽略一次：只移除当前出现，其他相同单词仍会提示。
  • 全部忽略：在当前工作区忽略该词的所有出现。
  • 添加到词典：把词加入当前词典的用户词典，适合人名、专有名词等长期有效内容。

这些操作会更新拼写统计，但不会改变正在使用的字幕筛选。

安装和切换拼写词典 ​

GridSubStudio 使用 Hunspell 格式词典，但不内置、下载或推荐具体词典。安装前请从可信来源取得适合目标语言和地区的词典，并确认其许可证允许你的使用方式。

认识 Hunspell 词典文件 ​

一套 Hunspell 词典至少包含两个配套文件：

  • .dic 是词条文件。第一行通常是词条数量，后续每行是一个词及其可选规则标记。
  • .aff 是规则文件，声明字符编码、前缀和后缀变化、替换与建议等规则。

两个文件必须来自同一套词典。不要把一个语言的 .aff 与另一个语言的 .dic 混用，也不要只复制 .dic。下载包中常见的文件名是 en_US.aff/en_US.dic、de_DE.aff/de_DE.dic；复制到 GridSubStudio 后，需要在各自子文件夹内改名为固定的 index.aff 和 index.dic。

应用会读取 .aff 中声明的编码和规则。除非你了解 Hunspell 格式，否则不要用文本编辑器重新保存、转换编码或改动规则标记，否则可能出现词典无法加载、正常词被误报或建议异常。

放入词典文件 ​

在 设置 → 词典 中：

  1. 点击 打开文件夹。
  2. 如果下载的是 ZIP 或其他压缩包，先完整解压；不要直接把压缩包放入词典目录。
  3. 为每套词典建立一个单独子文件夹，例如 en_US 或 de_DE。子文件夹名就是应用中显示的词典名称。
  4. 把配套的 .aff 和 .dic 放入该子文件夹，并分别命名为 index.aff 和 index.dic。
  5. 可以保留词典随附的 LICENSE、COPYING 或 README 作为许可记录；应用不会解析这些附加文件。
  6. 回到应用点击 刷新。
  7. 点击词典名称将其设为“启用中”。

目录结构应类似：

text
词典安装目录/
  en_US/
    index.aff
    index.dic
    LICENSE          （可选）
  de_DE/
    index.aff
    index.dic

应用只扫描词典安装目录的直接子文件夹。以下结构不会被识别：

text
词典安装目录/
  en_US.aff          （没有独立子文件夹）
  en_US.dic
  en_US/
    en_US.aff        （没有改为 index.aff）
    en_US.dic

切换和验证词典 ​

刷新后，只有同时包含两个必需文件的子文件夹才会出现在“已安装”列表中。点击一个词典名称后，它会显示为“启用中”；关闭词典管理器后，应用按新词典重新检查全部译文。

可故意输入一个常见错词并运行拼写检查，确认能显示错误和建议。不同 Hunspell 实现对少数复杂形态规则的结果可能不同；GridSubStudio 使用兼容 Hunspell 格式的本地检查引擎，不保证与 LibreOffice、Firefox 或其他 Hunspell/Nuspell 程序逐词完全一致。

安装多套地区词典时应保留清楚的文件夹名，例如 en_US、en_GB。GridSubStudio 不会自动把 en 映射为某个地区版本，也不会在选中词典缺失时回退到其他词典。

管理忽略词和用户词典 ​

词典管理器提供：

  • 忽略词：针对当前 CSV/项目工作区保存；可以添加词、勾选多项并移除。
  • 用户词典：属于当前词典，可跨项目使用；可以添加或批量移除自定义词。

在嵌套管理窗口关闭并返回词典管理器后，应用会统一重新检查，避免每次增删词都触发全量扫描。

遇到问题 ​

  • 刷新后没有出现词典：确认文件已经解压，位于安装目录的直接子文件夹中，并且准确命名为 index.aff 和 index.dic。
  • 词典无法加载：确认两个文件来自同一词典包，没有被编辑器改写编码；尝试重新从原始压缩包提取。
  • 选中的词典突然不可用：不要依赖自动回退。恢复原文件夹，或刷新后明确选择另一个已安装词典。
  • 刚改词典但结果未更新：关闭忽略词/用户词典窗口，再关闭词典管理器触发检查。
  • 没有建议：可以手动编辑、忽略一次，或在确认拼写正确时添加到词典。
  • 结果与其他软件不同：复杂词形规则可能存在兼容性差异；先核对词典版本和地区，再用实际字幕样例验证。
  • 检查大型项目较慢：可继续编辑；扫描会分批完成，避免阻塞工作区。
