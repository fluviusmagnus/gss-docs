设置与帮助 ​

调整使用体验、检查更新，并解决常见问题。

你可以在本页完成什么 ​

  • 切换界面语言、字体、字号和界面大小。
  • 管理隐藏列、拼写检查和机器翻译预设。
  • 检查更新、进入授权管理和清理缓存。
  • 查看快捷键、版本、许可证和临时诊断。

切换界面语言 ​

打开 设置 → 界面语言，选择 中文 或 English。语言偏好保存在本机，下次启动时自动恢复。

如果某项中文文案缺失，应用可能回退到英文；正常界面不应显示类似内部键名的文本。

调整字体和字号 ​

  • 编辑器字体：选择表格文本使用的字体。
  • 表格字号：调整字幕单元格字号，最小为 12px。
  • 界面大小：按 5% 调整 50%–150% 的整体 UI 比例。

较小窗口或高 DPI 屏幕可适当降低界面大小，再拖动表格与视频面板之间的分隔条。960×600 是常规完整编辑体验的建议最低尺寸；840×480 用于保证紧急情况下核心控件仍可访问。

显示或隐藏表格列 ​

启用 显示隐藏列 可查看默认隐藏的元数据列。关闭后只改变显示，不删除数据。使用 重置布局 可恢复列宽。

内部派生字段通常为只读；不要为了消除提示而直接修改自动计算列。

管理拼写检查 ​

  • 检查译文拼写：启用或关闭当前工作区的译文拼写扫描。
  • 词典：安装、刷新和选择 Hunspell 词典，管理忽略词和用户词典。

完整操作见质量检查。

管理机器翻译预设 ​

  • 机器翻译服务：管理连接、模型、能力和网络设置。
  • 机器翻译提示词：管理可复用的翻译指导。

预设在应用级共享；当前项目保存最近选择。详细说明见机器翻译。

检查和安装更新 ​

Windows 与 macOS 均使用 检查更新。两平台独立发布，版本号可能不同，应用只接收适合当前系统和架构的更新；Mac 更新不会安装 Windows 包。安装前先保存项目。当前 Mac 测试版的完整跨版本升级仍在验收中；失败时可从发布方下载对应系统的新安装包。

点击 检查更新：

  • 已是最新版本时，在设置菜单中显示当前版本提示。
  • 有更新时，弹窗显示新旧版本，可选择 稍后 或 安装更新。
  • 下载和安装过程中会显示进度；完成后应用重新启动。

自动检查失败通常保持安静；手动检查失败会显示错误，便于排查网络或发布端点。

打开授权管理 ​

点击 设置 → 授权，可以查看当前状态、生成机器码、添加或移除授权。获取授权、适用范围、换机和故障处理见独立的授权管理。

清除缓存并重启 ​

点击 清除缓存并重启 后，应用会要求确认；有未保存修改时会额外警告。

该操作清除应用拥有的本地 UI 缓存、旧版会话缓存和存储的文件句柄信息，然后重新加载应用。它不会成为删除项目文件夹的操作；项目模式的 project.json、workspace.csv 和项目草稿仍保留在磁盘。

执行前仍应正式保存重要工作。

查看快捷键 ​

点击 快捷键，或按 ? 打开帮助。对话框按编辑、表格和视频列出保存、撤销、查找、替换、播放、字幕导航和拼写检查快捷键。

详细表格见开始使用。

查看版本和第三方许可 ​

点击 关于 GridSubStudio 查看：

  • 当前应用版本。
  • 运行环境概要。
  • 第三方组件、版本和许可证。
  • 临时诊断开关。

启用和导出临时诊断 ​

临时诊断用于复现焦点、行选择、播放同步或滚动问题：

  1. 打开 关于 GridSubStudio。
  2. 启用 临时诊断。
  3. 在当前工作区复现问题。
  4. 点击 导出诊断包。

诊断只在当前工作区的有限内存缓冲中保存状态摘要，不记录字幕正文。切换项目、关闭工作区或关闭诊断时会清空。

解决常见问题 ​

macOS 首次启动被拦截 ​

当前 Mac 测试版未经公证。按首次启动的 Gatekeeper 放行步骤为应用单独放行。系统版本或架构不匹配不能靠放行解决，请先检查安装要求。

无法确认项目设置 ​

检查是否仍在导入，或是否存在无集数、重复集数、缺失文件、无匹配、多候选和导入错误。合法低置信结果只要求复核，不单独阻止确认。

项目已在其他窗口打开 ​

同一个项目不能由两个活动实例同时打开。回到原窗口正常关闭项目后重试；不同项目可以分别打开。

视频缺失 ​

字幕仍可编辑。打开 项目设置 重新导入视频并修正集数映射。不要通过把一个视频映射到多个集来绕过缺失提示。

拼写检查不可用 ​

打开词典目录，确认词典子文件夹同时包含来自同一套 Hunspell 词典的 index.aff 和 index.dic，刷新并选择该词典。完整目录结构和格式说明见安装和切换拼写词典。

机器翻译无法运行 ​

确认正在使用项目模式、已经导入字幕、至少有一个启用的服务预设、集数范围有效，并检查 Base URL、API Key、模型和代理。

字幕无法导出 ​

检查授权状态、工作区是否有行、ASS 源模板、输出文件名冲突和输出目录权限。授权相关提示见解决授权问题。

更新失败 ​

确认网络连接后重试手动检查。安装失败时保留当前版本，不要删除项目文件；记录错误并在需要时导出诊断包。
