效率工具 ​

使用查找、筛选、批量替换和行操作减少重复工作。

你可以在本页完成什么 ​

  • 精确查找并替换字幕文本。
  • 用多种条件筛选和排序工作区。
  • 批量断行、拆分、合并、新增或删除字幕行。
  • 使用右键菜单和快捷键处理选择范围。

查找字幕内容 ​

在表格工具栏的查找框输入内容，或按 Ctrl+F（macOS：Command+F）。匹配文字会在单元格中高亮。打开 高级查找 / 替换（Ctrl+H（macOS 也可使用；或点击按钮，避免 Command+H 隐藏窗口））后，可使用 上一个、下一个 在匹配间跳转。

查找从当前聚焦的匹配开始，而不是每次回到第一条。跳转会同步表格焦点和行选择。

替换单个或全部匹配 ​

  1. 输入 查找内容 和 替换为。
  2. 根据需要启用：
    • 仅搜索译文
    • 区分大小写
    • 使用正则表达式
    • 匹配整个单元格
  3. 点击 替换 修改当前匹配，或点击 全部替换。

启用 筛选结果 后，表格只显示匹配行。替换会进入撤销历史；如果查询或选项变化导致当前行不再匹配，焦点会移动到仍可见的有效行。

正则表达式无效时，面板会显示错误且不会执行替换。查找内容中的前导空格和纯空格查询会按原样保留。

使用批量替换规则 ​

批量替换用于反复应用一组替换对：

  1. 添加“查找/替换为”规则。
  2. 调整规则顺序；规则从上到下依次应用，前一条结果会进入下一条。
  3. 点击 应用到译文。
  4. 查看本次修改行数。

规则可从 bad_words.csv 导入或导出，并在应用级保存。多个窗口同时修改规则时，应用会要求选择重新加载、覆盖或取消，避免静默覆盖另一窗口的设置。

筛选需要处理的字幕 ​

快速筛选：

  • 点击 长行，只显示超过项目行长阈值的译文。
  • 点击 高 CPS，只显示超过最大 CPS 的行。

条件筛选：

  1. 点击 显示筛选。
  2. 选择字段、条件和筛选值。
  3. 添加多条规则。
  4. 用 规则逻辑 选择所有规则都满足（AND）或任一规则满足（OR）。

文本字段支持包含、不包含、等于、不等于、为空和非空；数值字段还支持大于、不小于、小于和不大于。

筛选只改变可见行，不删除数据。开启或关闭筛选时，多选范围会清理，只保留有效焦点行。

排序和调整表格视图 ​

  • 点击列标题切换升序、降序和默认顺序。
  • 拖动列边界调整列宽。
  • 在设置中启用 显示隐藏列 查看元数据列。
  • 点击 重置视图 清除筛选和临时视图。
  • 点击顶部 重置布局 恢复列宽。

排序和筛选后，复制、粘贴、全选和行工具均以当前可见行顺序为准。

批量选择字幕 ​

可以通过行标记、矩形范围、Ctrl（macOS：Command） 多范围或左上角全选框选择目标。工具栏会显示“已选”数量。

右键菜单提供 剪切、复制、粘贴、清空单元格、断行、拆分、合并、添加行和 删除选中。不可安全执行的命令会被禁用。

为字幕自动换行 ​

断行在译文中寻找接近中点的空格并插入字幕换行符；它仍保持一条字幕行和原时间范围。

  1. 选择一行或多行。
  2. 点击 断开选中行，或在右键菜单选择 断行。
  3. 查看完成摘要中的成功、无变化和失败数量。

没有合适空格、已经换行或超出项目行长限制时，原行会保留并计入摘要。

拆分字幕行 ​

拆分把一条字幕变成两条或多条：

  1. 选择目标行。
  2. 点击 拆分选中行。
  3. 应用优先按现有换行拆分，否则选择合适的空格。
  4. 新行按文本长度比例分配原字幕时间。

原行的集数和字幕元数据会保留。时间无效、没有可拆位置或不满足行长要求时不会修改该行。

合并字幕行 ​

  1. 选择同一集、时间顺序相邻的两行或多行。
  2. 点击 合并选中行。
  3. 如果时间严格连续，直接合并。
  4. 如果存在间隙，审查提示后选择 仍然合并 或取消。

合并后的时间从第一行开始到最后一行结束，文本字段用字幕换行连接。不同集或不相邻的可见行不能合并。

新增和删除字幕行 ​

  • 添加行：在当前焦点行下方插入一条空译文行，并保留必要的行结构。
  • 删除选中：删除选中的可见行。完成后焦点移动到下一条仍存在的可见行；没有下一条时移动到上一条。

新增、拆分、合并和删除都会进入撤销历史，并触发质量和拼写结果更新。

使用右键菜单和快捷键 ​

在单元格或选区内右键可打开紧凑操作菜单。右键选区外的单元格会先把它设为当前选择。文本输入框仍使用系统原生右键菜单。

常用快捷键见开始使用。

遇到问题 ​

  • 行工具不可用：确认已选择可见行；合并至少需要两条同集相邻行。
  • 粘贴没有影响隐藏行：这是预期行为，筛选时只向当前可见行粘贴。
  • 断行和拆分结果不同：断行保留一条字幕；拆分会生成多条字幕并重新分配时间。
  • 批量替换规则冲突：选择重新加载可保留磁盘版本；只有明确选择覆盖才会写入当前窗口版本。
